# Codex skills

Personal Codex skills for focused GitHub workflows:

- `tackle-issue`: take an issue from intake through a submitted pull request.
- `prepare-pull-request`: shape, publish, and finish concise reviewable pull requests.
- `report-github-issues`: report unrelated findings without widening active work.

Each skill is self-contained in its own directory and can be copied into your Codex skills directory.
